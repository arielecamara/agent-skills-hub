# 🌿 Universal Life Assistant Skill (Template)

A clean, open-source skill template for daily habit tracking, routine logging, and work progress management across universal AI agents (Antigravity, Cursor, Claude, ChatGPT, Windsurf).

---

## 📌 Overview

This template provides a standardized structure for tracking daily life, health, deep work, and project milestones without forcing bloated to-do lists.

---

## 🚀 How to Use

1. Copy `SKILL.md` into your agent's skill or rules directory:
   - **Antigravity / VS Code:** Save to `.agent/skills/life-assistant/SKILL.md`.
   - **Cursor:** Save to `.cursor/rules/life-assistant.mdc`.
   - **Claude / ChatGPT:** Add to Project Knowledge or Custom Instructions.
2. Copy `config.example.md` to `config.md` and customize your daily checklist.
3. Start interacting:
   - *"Initialize today's daily log."*
   - *"I finished morning routines and completed the project documentation."*
